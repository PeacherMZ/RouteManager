# 验证范围与记录

仅记录可公开的验证信息。真实路由、接口标识、用户配置、诊断输出和截图不随源码发布。

## 2026-10-14：2.1.0 跨平台改造

已在 Windows 开发环境完成：

- 前端 10 项单元测试和 TypeScript/Vite 生产构建。
- Rust 51 项测试：4 项 PowerShell 管道/接口契约、34 项核心、11 项平台/存储、2 项发布契约测试；覆盖原生持久服务的多作用域预览及活动残留核验。
- Windows PowerShell 5.1 模拟 NetTCPIP 契约测试。
- Chromium、WebKit 各 9 项演示交互测试（共 18 项），包括 macOS 能力显示；检查紧凑布局与主题截图。
- Windows x64 release 应用编译；更新 artifacts/app/RouteManager.exe 与根目录快捷方式。
- 正式 Windows 离线安装包生成（约 210 MiB），包含微软签名验证通过的 WebView2 离线运行时；SHA-256 和运行副本一致性已核对。
- NSIS 自定义模板实际封装契约测试：移除用户数据删除行为，拒绝运行中覆盖和降级。契约测试包跳过 WebView2，仅用于验证模板，不作为正式离线安装包交付。
- 工作流 YAML、双平台发布门禁、固定 Actions 提交、安装器数据保护与版本一致性契约。
- 源码差异检查及常见密钥/个人绝对路径扫描；未读取现有私人 data/legacy，未修改真实路由或系统 hosts。

- 同一应用成功构建完整离线包（209.92 MiB）和轻量联网包（3.10 MiB），后者减少约 98.5%。两份 SHA-256 及运行副本一致性核对通过。
- 前端生产构建、两项安装/发布契约和构建/发布脚本语法检查通过；本次未修改应用业务逻辑。
- 发布门禁同时要求 Windows 两种安装包及 macOS PKG。轻量包缺少 WebView2 时需联网，不能替代无运行时环境下的完整离线包。
- 未执行安装器实机安装；已有/缺失 WebView2、断网失败和两种包交叉升级的验收见 acceptance.md。

- Windows 新装默认目录调整为 `C:\Program Files\RoutingTableManager`，已有安装沿用原目录。两种安装包重新构建、SHA-256 及运行副本一致性检查通过，安装/发布契约两项通过；未执行实际安装。

## 验收边界

所有自动化路由修改使用模拟器，hosts 测试使用临时文件。浏览器演示、静态契约和编译成功不能替代真实系统写入、安装及重启验证。公开 Release 前按 [验收清单](acceptance.md) 完成上述实机项目；保持草稿直至验收完成。
