# 验证范围与记录

本文件只保留可公开的验证信息。本机路由、接口、配置数量、设备信息、截图和诊断输出不随源码发布。

## 既有自动化覆盖

- 前端：参数校验、筛选、配置与系统状态区分、批量加入分组，以及慢快照下的配置保存与刷新竞争。
- Rust：独立数据库迁移、合成旧格式 YAML 导入、路由匹配、持久记录残留、外部冲突、部分失败与恢复。
- PowerShell：模拟 NetTCPIP 契约、私有进程复用、多请求传输、错误恢复、超时与退出清理。
- Playwright：演示模式下的交互、布局与主题；截图仅写入被忽略的产物目录。

既有覆盖范围不代表每次提交均运行了所有检查；执行方法见 README.md。

- 前端 10 项单元测试、TypeScript/Vite 生产构建通过。

- 审查暂存文件、常见凭据特征、内部地址、个人路径、旧配置内容重合及图标元数据；公开源码使用虚构示例，本地数据和构建产物保持忽略。
- 本轮未执行真实系统路由或 hosts 写入，也未进行重启验收。

## 实机验收边界

自动化路由写入使用模拟器，hosts 测试使用临时文件。真实路由写入、重启后的持久行为、UAC、高 DPI 和目录搬迁需按 [验收说明](acceptance.md) 在隔离 Windows 环境中验证，不能以模拟测试替代。
