# 验收说明

## 自动化范围

- Rust 集成测试仅调用 Fake RouteSystem，不接触真实路由；hosts 测试仅使用临时目录。
- 前端单元测试覆盖 IPv4 参数、过滤、持久状态和实际记录转换。
- Playwright 使用 Edge 与开发环境的 ?demo=1，验证主界面、IPv6 只读、变更预览、清除受管理路由仍保留配置、配置保存不修改系统、主题和 hosts。
- 演示环境只能验证交互，不能证明 Windows 路由写入正确。
- 本机 inspect 示例只读查询 NetTCPIP，创建／迁移指定目录的 SQLite，但不会调用路由增删改。

## 隔离 Windows 实机验收

在有独立测试网卡的 Windows 虚拟机中执行，使用实验网段，不使用工作机的默认路由测试：

1. 新增临时 IPv4 路由，确认仅 ActiveStore 存在；重启后消失。
2. 新增持久 IPv4 路由，确认两种存储均存在；重启后仍生效。
3. 移除持久路由，确认两种存储均无记录；重启后不重现。
4. 同目标、不同网关／不同接口并存，删除仅影响准确目标。
5. 外部修改 metric 后执行旧预览，确认拦截并要求重新预览。
6. 网卡断开或接口索引变化，确认提示正确；不会误操作其他网卡。
7. 更新 metric 后核对活动和持久记录；替换失败后核对旧静态记录和恢复说明。
8. 清除全部受管理路由，确认未匹配路由和配置库保留。
9. 修改系统自动路由，核验系统拒绝／自动重新生成时能明确显示；不循环删除。
10. 验证取消 UAC 无系统修改，启动快捷方式、窗口显示及 WebView2 运行正常。
11. hosts 外部编辑冲突、UTF-8/UTF-16 和系统编码往返，确认备份内容完整。
12. 100%、150%、200% DPI，浅色/深色和最小窗口下检查对话框及表格滚动。

## 发布交付检查

- 前端构建、Rust 测试、Rust 桌面发布构建完成。
- 根目录 LNK 指向 artifacts/app/RouteManager.exe；CMD 使用相对路径定位应用及 data。
- 从不同当前工作目录启动仍使用同一数据库。
- 复制便携运行目录到包含中文和空格的新位置，使用 CMD 能启动；重新生成 LNK 后可用。
- 清理脚本只处理 artifacts，数据和 legacy 文件不变。

真实系统写入与重启项需在隔离环境执行；未执行的项目应记录为“未验证”，不能用模拟测试替代。
