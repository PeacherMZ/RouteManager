# 验收说明

## 自动化范围

- Rust 集成测试仅调用 Fake RouteSystem，不接触真实路由；hosts 测试仅使用临时目录。
- 前端单元测试覆盖 IPv4 参数、过滤、持久状态和实际记录转换。
- Playwright 使用 Chromium 和 WebKit 与开发环境的 ?demo=1，验证主界面、IPv6 只读、变更预览、清除受管理路由仍保留配置、配置保存不修改系统、主题和 hosts。
- 演示环境只能验证交互，不能证明任何平台的真实路由写入正确。
- inspect 示例只读查询当前平台原生路由，创建／迁移指定目录的 SQLite，但不会调用路由增删改。

## 隔离 Windows 实机验收

在有独立测试网卡的 Windows 虚拟机中执行，使用实验网段，不使用工作机的默认路由测试：

1. 新增临时 IPv4 路由，确认仅 ActiveStore 存在；重启后消失。
2. 新增持久 IPv4 路由，确认两种存储均存在；重启后仍生效。
3. 移除持久路由，确认两种存储均无记录；重启后不重现。
4. 同目标、不同网关／不同接口并存，删除仅影响准确目标。
5. 外部修改 metric 后执行旧预览，确认拦截并要求重新预览。
6. 网卡断开或接口索引变化，确认提示正确；不会误操作其他网卡。
7. 更新 metric 后核对活动和持久记录；替换失败后核对旧静态记录和恢复说明。
8. 清除全部受管理路由，确认未匹配路由和配置库保留。
9. 修改系统自动路由，核验系统拒绝／自动重新生成时能明确显示；不循环删除。
10. 验证取消 UAC 无系统修改，启动快捷方式、窗口显示及 WebView2 运行正常。
11. hosts 外部编辑冲突、UTF-8/UTF-16 和系统编码往返，确认备份内容完整。
12. 100%、150%、200% DPI，浅色/深色和最小窗口下检查对话框及表格滚动。

## 发布交付检查

- 前端构建、Rust 测试、Rust 桌面发布构建完成。
- 根目录 LNK 指向 artifacts/app/RouteManager.exe；CMD 使用相对路径定位应用，不再指定旧 data。
- 从不同当前工作目录启动仍使用同一数据库。
- 安装到包含中文和空格的路径，用户目录仍保持不变。
- 清理脚本只处理 artifacts，数据和 legacy 文件不变。

真实系统写入与重启项需在隔离环境执行；未执行的项目应记录为“未验证”，不能用模拟测试替代。

## 隔离 macOS 13+ Apple Silicon 验收

1. 原生 arm64 应用无 Rosetta 依赖；验证 WKWebView、中文路径、深浅主题与错误对话框。
2. 临时 IPv4 路由增删改；验证 ifscope、直连网关、同前缀不同网关、不同接口及 IPv6 只读。
3. 网络服务 AdditionalRoutes 新增/删除/替换，核对同服务未命中条目和其他配置不变。
4. 退出应用后重启，持久路由由系统恢复；删除后再次重启不重现。确认无新增启动项、LaunchAgent 或 LaunchDaemon。
5. 断开/重连、网卡重编号、服务改名、停用服务、多个服务共享接口；歧义不猜测，不支持的接口不能勾选持久化。
6. 修改预览后由外部工具改变原生配置，执行应拒绝过期记录，保留未知变化。传输断开不能自动重放写入。
7. 取消授权无系统修改；助手批次结束退出；错误或超时如实报告。验证套接字无未授权调用入口。
8. hosts 保存保留 UTF-8/BOM/UTF-16、换行、root 属主、权限及扩展元数据；外部修改冲突拒绝覆盖；备份位于用户目录。

## 安装与数据持久化验收

1. 全新 Windows 10/11（无 WebView2、无网络）安装 EXE；验证离线运行时安装和程序启动。
2. Windows 普通用户通过另一管理员账户完成 UAC，配置仍写入原用户 LocalAppData。两个用户互不串库，取消 UAC 不创建空库。
3. macOS PKG 仅安装到 Applications；验证最低系统版本、arm64、ad-hoc 签名和首次安全放行流程。
4. 安装旧测试版本，保存配置、分组、设置、历史、备份与导出，再覆盖升级；逐项比较数据保留。不得用现有私人 data 作为样例。
5. 运行时覆盖安装应中止；降级应拒绝；卸载重装仍读取原有用户数据；卸载器不提供删除用户数据选项。
6. 新版目录为空时不扫描旧 data/legacy；数据库结构更高、损坏或备份失败均不得回退到空库。
7. 推送匹配的测试版本标签，两平台成功后才生成草稿；任一平台失败不发布；人工公开发布后自动任务不得覆盖它。

### Windows 轻量包补充验收

- 已安装 WebView2：断网运行 online 安装包，验证复用运行时及正常启动。
- 未安装 WebView2：联网安装并验证运行时下载、安装和应用启动；断网时明确失败，不报告安装成功。
- online 与完整离线包交叉覆盖升级，验证安装位置、用户数据与版本保护一致。
